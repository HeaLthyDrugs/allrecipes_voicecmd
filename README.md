# AllRecipes 🍳

A modern recipe discovery app built with Next.js featuring voice commands and smart search.

![Recipe App Preview](./public/images/1.png)

## Features

- 🔍 Smart recipe search
- 🎤 Voice commands
- 📱 Responsive design
- ⚡ Fast performance

## Quick Start

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
